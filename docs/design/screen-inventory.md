# Ani Manager Screen Inventory

## MVP screens

### `/`

- 대시보드 홈
- 추천 요약
- 감상 보드 요약
- 다이제스트 미리보기

### `/onboarding`

- 취향 수집 시작
- 작품 선택
- 캐릭터/연출 선호 입력
- 톤/감정선 선호 선택

### `/recommendations`

- 시즌 추천 리스트
- 추천 정렬과 필터
- 추천 이유와 시청 액션

### `/titles/[id]`

- 작품 상세
- 감상 상태 변경
- 입문 평가
- 추천 근거

### `/watchboard`

- 감상 상태 보드
- 보는 중/보류/완주/하차/예정

### `/digest`

- 주간 개인화 다이제스트

## API-backed interactions

- 온보딩 제출
- 추천 생성 요청
- 상태 변경 요청
- 시즌 카탈로그 조회
- 다이제스트 조회
