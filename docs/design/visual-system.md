# Ani Manager Visual System

## Visual Direction

Ani Manager는 차갑고 기술적인 대시보드보다, 취향을 읽어주는 에디토리얼 보드처럼 보여야 합니다.

핵심 무드는 다음과 같습니다.

- 종이 질감이 있는 따뜻한 베이스
- 시즌 감성을 암시하는 컬러 포인트
- 정보 밀도는 높지만 압박감은 낮은 레이아웃
- 장식보다 해석 가능한 위계

## Color roles

- Background: 부드러운 크림/샌드 톤
- Surface: 반투명한 카드형 표면
- Accent: 오렌지 브릭 또는 시즌 포인트 컬러
- Text: 진한 브라운 계열
- Support: 일정/OTT/태그를 구분하는 보조 컬러

## Typography direction

- 헤드라인: 문학적인 인상이 있는 세리프
- 본문: 읽기 좋은 시스템 산세리프 또는 고전적인 세리프 혼합
- 메타 정보: 작은 uppercase 또는 condensed 스타일

## Layout principles

1. 홈에서는 "이번 주의 선택" 영역이 가장 강해야 한다.
2. 카드 목록만 반복하지 말고, 강조 카드와 보조 카드의 위계를 만든다.
3. 정보량이 많은 상세 화면은 블록형 편집 레이아웃으로 나눈다.

## Motion direction

- 카드 등장 시 가벼운 stagger
- 상태 변경 시 작은 하이라이트 전환
- 다이제스트 갱신 시 숫자/문구만 부드럽게 치환

## Accessibility baseline

- 본문 대비 충분히 확보
- 상태색만으로 의미를 전달하지 않기
- 주요 버튼과 링크는 충분한 터치 영역 유지
