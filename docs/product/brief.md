# Ani Manager Product Brief

## Goal

Ani Manager는 유저의 감상 기록과 취향 신호를 학습해, 이번 시즌에 볼 만한 애니메이션을 자동으로 골라주고 감상 결정을 돕는 개인용 AI 애니 취향 매니저입니다.

핵심 목표는 "무엇을 볼지 고르는 피로"를 줄이고, "왜 이 작품이 나에게 맞는지"를 설명 가능한 방식으로 제공하는 것입니다.

## Target User

### Primary user

- 매 시즌 볼 작품을 고르는 데 시간이 오래 걸리는 애니 시청자
- 감상 이력은 많지만 취향을 구조화해서 관리하지 못한 유저
- 커뮤니티 평판보다 자신의 취향에 맞는 추천을 더 중요하게 여기는 유저

### Secondary user

- OTT 제공 여부와 방영 일정을 함께 관리하고 싶은 유저
- 하차 여부를 빠르게 판단하고 싶은 유저
- 매주 개인화된 감상 다이제스트를 받고 싶은 유저

## Core User Journey

1. 유저는 좋아한 작품, 싫어한 작품, 최애 캐릭터, 선호 연출을 입력한다.
2. 서비스는 취향 프로파일을 만들고 현재 시즌 작품 카탈로그를 정규화한다.
3. AI는 작품 분위기, 관계성, 전개 속도, 감정선을 태깅한다.
4. 서비스는 유저에게 맞는 작품을 추천하고 추천 이유를 설명한다.
5. 유저는 작품을 보는 중, 보류, 완주, 하차 상태로 정리한다.
6. 서비스는 시청 기록을 바탕으로 추천 정확도와 주간 다이제스트를 개선한다.

## MVP Scope

### In scope

- 취향 온보딩
- 시즌별 추천 리스트
- 추천 이유 설명
- 1~3화 기준 입문 평가
- 감상 상태 관리
- OTT 제공 여부와 방영 일정 노출

### Out of scope

- 커뮤니티 피드
- 소셜 기능
- 공개 리뷰 작성
- 고급 협업 기능

## Product Principles

1. 혼자 써도 바로 가치가 있어야 합니다.
2. 추천은 점수보다 설명이 중요합니다.
3. 데이터가 부족해도 규칙 기반으로 초기 가치를 제공해야 합니다.
4. 유저가 감상 상태를 정리할수록 추천이 더 좋아지는 선순환 구조여야 합니다.
5. 서비스 용어와 상태값은 단순하고 예측 가능해야 합니다.

## Risks

- 시즌 카탈로그와 OTT 정보의 최신성 유지
- AI 태깅 품질 편차
- 초기 유저 데이터 부족으로 인한 추천 품질 한계
- 추천 근거가 피상적으로 느껴질 위험

## Success Metrics

- 온보딩 완료율
- 첫 추천 클릭률
- 추천 후 실제 시청 전환율
- 시청 상태 업데이트 비율
- 주간 다이제스트 재방문율

## Next Decisions

- 온보딩 질문 수와 입력 방식
- 실제 메타데이터 소스 우선순위
- 추천 엔진의 규칙 기반 1차 버전 범위
- 다이제스트 발송 채널과 빈도
